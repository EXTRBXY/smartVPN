# Чек-лист тестовой эксплуатации

Сборка для повседневного использования — `localRelease`: без режима отладки, с R8, с `FLAG_SECURE` (скриншоты приложения чёрные — это нормально), подписана debug-ключом этого компьютера. Собирается `build-release-apk.bat` или командой `.\gradlew.bat :androidApp:nonDebugApk`, файл — `androidApp/build/outputs/apk/localRelease/androidApp-localRelease.apk`. Версия видна на экране «Диагностика».

## Один раз после установки
- [ ] Импорт профиля: ссылкой `vless://` и через QR-код.
- [ ] Подключение кнопкой в приложении; статус «Подключено», счётчики трафика растут.
- [ ] Плитка в шторке: добавить через «Изменить», включить/выключить VPN, статус совпадает с приложением.
- [ ] Отключение кнопкой в уведомлении — плитка и приложение показывают «Отключено».
- [ ] Редактирование профиля: Security выбирается из `tls / reality / none`; сохранение работает.

## В течение дня (обычное использование)
- [ ] Смена сети Wi-Fi ↔ мобильная при включённом VPN — трафик продолжает идти.
- [ ] Блокировка экрана на долгое время (ночь) — утром VPN в ожидаемом состоянии, плитка не врёт.
- [ ] Перезагрузка телефона: при включённом «Подключаться после перезагрузки» VPN поднимается сам; при выключенном — плитка показывает «Выкл», а не «Вкл».
- [ ] Включение другого VPN-приложения — наш VPN отключается с понятной причиной.
- [ ] Маршрутизация («Только выбранные приложения» / «Все, кроме выбранных») — выбранные приложения ведут себя как ожидается; после переключения на «Весь трафик» и обратно выбор приложений сохранился.
- [ ] «Постоянный VPN» (Always-on) в настройках Android: после перезагрузки и после обновления приложения туннель поднимается сам.
- [ ] Если VPN неожиданно пропал — он должен вернуться сам в течение ~15 минут без открытия приложения; в «Диагностике» при этом видно «Watchdog: tunnel missing after process start».
- [ ] Настройки DNS (System / DoH) — сайты открываются.

## Если что-то пошло не так
1. Откройте «Диагностика» → «Последние события»: там причина каждой неудачной попытки подключения (код вида `smoke_proxy_failed [...]`) и события хранилища (`Storage: ...`).
2. «Диагностика» → «Копировать» — отчёт без секретов (UUID и ключи в него не попадают). Пришлите его вместе с описанием: что делали, что ожидали, что произошло, примерное время.
3. Не удаляйте приложение, чтобы «починить»: удаление стирает профили.

## Что известно заранее
- «Задержка» и «Выбрать самый быстрый» измеряют только TCP-соединение с сервером, а не работоспособность VLESS/Reality.
- Строгая блокировка трафика без VPN (Kill Switch) включается в настройках Android («Постоянная VPN» + «Блокировать подключения без VPN»), а не в приложении.
- После «Принудительно остановить» (и свайпа из недавних, если прошивка делает при этом force-stop) VPN сам не вернётся до следующего запуска приложения — так устроен Android.
- Язык приложения (русский / английский) меняется в настройках Android: «Приложения» → Nothing Mobile → «Язык».
