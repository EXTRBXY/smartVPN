# Nothing Mobile VPN

Android-first мобильный VPN-клиент с архитектурным заделом под iOS.

## Документация

Подробное описание архитектуры, жизненного цикла VPN, безопасности и сборки — в [docs/](docs/README.md). Правила для AI-агентов — в [CLAUDE.md](CLAUDE.md).

## Текущее состояние

Версия **0.3.0** (`versionName` в `androidApp/build.gradle.kts`), ядро sing-box **1.14.3** (встроенный `libbox.aar`, только arm64). Android: minSdk 26, targetSdk 35, сборка под SDK 37. Интерфейс на русском и английском.

## Структура проекта

- `androidApp` — Android приложение и platform-адаптеры (`VpnService`, runtime, permissions).
- `shared` — Kotlin Multiplatform shared-логика (`domain` + `application`).
- `androidApp/libs/libbox.aar` — нативная обёртка sing-box (libbox), лежит в репозитории; пересобирается `scripts/build-libbox-aar.ps1` (см. [docs/build-and-test.md](docs/build-and-test.md)).

## Что сделать вручную (обязательно)

1. Установить Android Studio (последняя стабильная), Android SDK и JDK 17.
2. Установить платформу Android SDK 37: `sdkmanager "platforms;android-37.0"` (или через SDK Manager в Android Studio).
3. Открыть проект в Android Studio и выполнить Gradle Sync. `libbox.aar` уже в репозитории; если его нет — сборка остановится на `checkLibboxAar` с подсказкой.

## Возможности приложения

- Единая кнопка подключения, плитка быстрых настроек и статистика трафика ядра.
- Импорт VLESS-ссылок и QR-кодов, экспорт с предупреждением о секретах, копирование профилей и избранное.
- Проверка TCP-доступности сервера, выбор самого быстрого доступного профиля и подтверждение переподключения при смене профиля.
- Маршрутизация: весь трафик, только выбранные приложения или все, кроме выбранных; у каждого режима свой список, переключение режима его не стирает. Поиск, фильтры, массовый выбор и сохраняемые наборы приложений.
- Системный DNS или DoH, локальные DNS-домены и приложения-исключения, проверка доступности DNS-сервера.
- Настройки автостарта после загрузки, автоматического восстановления, недоверенных Wi-Fi и фоновой проверки туннеля.
- Поддержка системного «Постоянного VPN» (Always-on); туннель поднимается сам после перезапуска сервиса системой, а сторож (JobScheduler, раз в 15 минут) — после аварийного завершения приложения.
- Профили, секреты и настройки хранятся в одном зашифрованном файле (ключ в Android Keystore).
- Диагностический экран, ограниченный журнал событий, копирование и отправка отчёта.

Автоматические функции по умолчанию выключены. Для определения имени Wi-Fi нужен доступ к точному местоположению; Android/прошивка могут дополнительно ограничивать работу в фоне. Автостарт требует ранее выданного разрешения VPN и активного профиля.

Строгий Kill Switch включается пользователем в системных настройках Android: «Всегда включённый VPN» и «Блокировать соединения без VPN». Приложение предоставляет переход и инструкции, но не может само изменить эти системные параметры.

Проверка задержки профиля и DNS-сервера измеряет TCP-соединение, а не подтверждает UUID, Reality или корректность DNS-ответа. После старта VPN выполняется HTTPS-проверка через туннель (`https://www.gstatic.com/generate_204`). Опциональная фоновая проверка повторяет её раз в минуту и инициирует восстановление после двух сбоев. Запрос внешнего IP выполняется только по кнопке через `https://api.ipify.org`.

DNS-исключения используют поддерживаемые ядром правила `domain_suffix` и `package_name`; см. [DNS rules](https://sing-box.sagernet.org/configuration/dns/rule/). Для приложений, использующих собственный DoH, системные DNS-правила не заменяют встроенный резолвер приложения.

## Проверка и сборка

```powershell
.\gradlew.bat :shared:testAndroidHostTest :androidApp:testDebugUnitTest :androidApp:assembleDebug :androidApp:lintDebug
```

APK: `androidApp/build/outputs/apk/debug/androidApp-debug.apk`.

Сборка для повседневного использования (`localRelease`: без отладки, R8, подпись debug-ключом этого компьютера) — `build-release-apk.bat` или `.\gradlew.bat :androidApp:nonDebugApk`; файл — `androidApp/build/outputs/apk/localRelease/androidApp-localRelease.apk`. Обе сборки ставятся друг поверх друга с сохранением данных (`adb install -r`).

При ручной проверке на телефоне проверьте подключение, смену Wi-Fi/мобильной сети, выключение из уведомления/плитки, QR-импорт, DNS-исключения и поведение системной блокировки без VPN. Не запускайте инструментальные тесты поверх единственной копии пользовательских данных без резервной копии: Android test runner может удалить тестируемый APK после завершения.

## Ограничения

- Полноценная iOS сборка и подпись требуют macOS.
- Секреты и ключи хранить только в защищённом хранилище (Android Keystore).
